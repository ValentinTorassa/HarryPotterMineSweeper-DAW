# Harry Potter Minesweeper

A Harry Potter-themed **Minesweeper game** with immersive visual and sound effects, magical UI and animations inspired by the wizarding world.

## Features

- **Dark/Light Mode**: Toggle between visual themes
- **Background Music**: Harry Potter soundtrack with full audio control
- **Ranking System**: Save and view high scores locally
- **Multiple Difficulties**: Easy, Medium, and Hard levels
- **Special Effects**: Magical animations and themed win/lose effects
- **Responsive Design**: Fully mobile-friendly and accessible

## How to Play

1. Open `index.html` in your browser
2. Select a difficulty level
3. Left-click cells to reveal them
4. Right-click (or long press on mobile) to flag/unflag mines
5. Avoid the mines and reveal all safe cells to win!

## Technologies Used

- **HTML5** — Page structure
- **CSS3** — Styling, transitions, and responsive layout
- **JavaScript** — Game logic, UI interaction
- **LocalStorage** — Stores settings and player scores persistently
